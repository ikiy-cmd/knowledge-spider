# Knowledge Spider · 蛛知

> 供学习参考。

基于 React、TypeScript 和 Vite 的知识检索可视化演示项目。将主题、文档和知识片段组织为球面蛛网，通过蜘蛛沿网移动的动画展示检索与证据浏览过程。

## 功能

- 展示知识图谱，支持缩放、节点选择和视角跟随。
- 在浏览器内使用 BM25 检索知识片段，查看结果与证据。
- 支持自动演示、暂停、重播和速度控制。
- 支持粘贴文本或导入 `.txt`、`.md`、`.markdown` 文件，建立临时知识主题。

导入内容保存在当前页面的内存中，刷新页面后会丢失。项目当前没有接入远程大模型或服务端存储。

## 本地运行

安装 Node.js 和 pnpm 后，在项目目录执行：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开 <http://127.0.0.1:4173/>。

```sh
pnpm test     # 运行单元测试
pnpm build    # 类型检查并生成生产构建
pnpm preview  # 本地预览构建结果
```

## 目录

- `src/components/`：界面组件。
- `src/engine/`：交互与演示状态控制。
- `src/graph/`：知识图谱构建、布局和相机。
- `src/render/`、`src/spider/`：画布渲染与蜘蛛动画。
- `src/lib/`：文本分析、检索和本地导入。
- `src/data/`：演示知识数据。
- `scripts/`：浏览器交互检查与截图脚本；其中的浏览器可执行文件路径需要按本机环境调整，运行前需启动开发服务器。

依赖目录、构建结果、本地环境配置和调试截图不纳入版本管理。
